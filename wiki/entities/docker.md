# Docker Inc.

**Type:** Organization / DevOps Platform Company
**Also known as:** Docker
**URL:** [https://www.docker.com/](https://www.docker.com/)

## TL;DR

Docker is the dominant container platform for building, shipping, and running applications. In 2026 it has expanded aggressively into AI/Agent infrastructure with free Docker Hardened Images, Docker MCP (200+ verified MCP servers as containers), and agentic-stack orchestration. The platform serves 24M+ users with 14M+ images and 11B+ monthly downloads.

## Key Products

- **Docker Desktop** — Local container runtime and developer tool
- **Docker Hub** — World's largest library of container images (14M+ images)
- **Docker Hardened Images (DHI)** — Free Apache 2.0 images with near-zero CVEs, SBOMs, SLSA Level 3
- **Docker MCP** — 200+ verified MCP servers containerized with security controls
- **Docker Compose** — Multi-container application orchestration

## Ecosystem Scale

- 24M+ users
- 14M+ images
- 11B+ monthly downloads
- 200+ verified MCP servers
- 1000+ hardened images and Helm charts

## Security Innovations

- **Five Pillars:** Minimal images, signed provenance, complete SBOMs, VEX insights, transparent verification
- **Rug Pull / Tool Poisoning Protection** — Signed and verified MCP servers with runtime isolation
- **Extended Lifecycle Support** — Multi-year CVE patches for EOL images
