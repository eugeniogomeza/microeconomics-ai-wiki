# Harrison Kinsley

**Type:** Person  
**AKA:** Sentdex  
**Known For:** Creator of Sentdex, one of the longest-running Python/ML education channels on YouTube

## TL;DR

Harrison Kinsley is an American software developer and educator best known for his YouTube channel Sentdex and website pythonprogramming.net. Active since ~2012, Sentdex has produced 1,300+ videos spanning Python programming, machine learning, deep learning, reinforcement learning, computer vision, financial analysis, and game development. Kinsley's style is unscripted, practical, and code-forward: he opens an editor, writes code, runs it, and debugs live.

## Profile

Kinsley started Sentdex as a way to document his own learning. Over a decade, it grew into one of the most comprehensive free Python/ML education resources. Unlike polished courses, Sentdex videos often show the messy reality of programming: typos, bugs, Stack Overflow searches, and iterative debugging. This raw authenticity makes the content highly relatable for self-taught developers.

Key contributions:
- One of the first popular "neural network from scratch" series using only NumPy.
- Practical reinforcement learning tutorials using OpenAI Gym before RL became mainstream.
- Deep learning courses covering both TensorFlow and PyTorch.
- Applied projects: trading bots, game AI, computer vision pipelines.
