# Skills.sh

**Type:** Product / Agent Skills Directory
**URL:** [https://www.skills.sh/](https://www.skills.sh/)
**Command:** `npx skills add <owner/repo>`

## TL;DR

Skills.sh is the open agent skills ecosystem — a universal directory for reusable AI agent capabilities. With 419,430+ total installs and support for 20+ agents (Claude Code, Cursor, Codex, Copilot, Droid, OpenClaw, etc.), it functions as an npm-like registry for agent abilities contributed by organizations and individual developers.

## Ecosystem Scale

- 419,430+ all-time installs
- 20+ supported agents
- Top contributors: Anthropic, Microsoft, Vercel Labs, Matt Pocock, Paul Bakaus
- Skills span frontend design, cloud deployment, document processing, marketing, code review
