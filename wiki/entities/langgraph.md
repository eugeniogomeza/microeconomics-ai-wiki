# LangGraph

**Type:** Product / Framework  
**Developer:** LangChain (Harrison Chase)  
**URL:** [langchain-ai.github.io/langgraph](https://langchain-ai.github.io/langgraph/)  
**Related:** [[langchain]], [[crewai]], [[autogen]], [[ai-agent-harness]]

## TL;DR

LangGraph is a framework for building stateful, multi-actor agent applications with LLMs. It excels at complex workflows requiring fine-grained control over state transitions. Along with LangChain, it forms the backbone of many enterprise agent applications.

## Comparison to Other Frameworks

| Framework | Strength | Use Case |
|-----------|----------|----------|
| LangGraph | Stateful workflows, fine-grained control | Production apps with complex branching logic |
| CrewAI | Multi-agent collaboration, role-based | Team simulations, project management |
| AutoGen / AG2 | Conversational multi-agent | Research agents, code generation |
| Hermes | Personal IT agent, self-hosted | Homelabs, individual automation |
| OpenAI Agents SDK | Quick prototyping | Simple agent apps on OpenAI stack |
