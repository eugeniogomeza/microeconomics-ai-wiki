# OpenClaw

**Type:** Product / AI Agent Harness  
**Related:** [[hermes-agent]], [[nous-research]], [[persistent-memory]], [[ai-agent-harness]]

## TL;DR

OpenClaw is an open-source AI agent harness that was one of the first to gain widespread attention. It is feature-rich and highly configurable but has been criticized for becoming bloated, unstable over time, and feeling more like a "project" than a "product." NetworkChuck and others have switched to Hermes as a lighter, more reliable alternative.

## Relationships

- [[peter-steinberger]] — Creator; joined OpenAI in Feb 2026 while maintaining project open-source
- [[nous-research]] — Primary competitor (Hermes Agent)
- [[anthropic]] — Claude frequently used as OpenClaw's backend model

## Comparison to Hermes

| Dimension | OpenClaw | Hermes |
|-----------|----------|--------|
| Memory | Auto-growing, can bloat | Hard-capped, auto-curated |
| Skills | Marketplace/downloads | Self-generated from use |
| Stability | Degrades with updates | Reported as more stable |
| Philosophy | Configurable everything | Opinionated, fewer options |
| Vibe | Functional/utilitarian | Fun, aesthetic, product-like |
