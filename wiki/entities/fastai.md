# fastai

**Type:** Organization / Open-Source Library  
**Parent:** fast.ai

## TL;DR

A deep learning library built on PyTorch that provides high-level APIs for training state-of-the-art models quickly and easily. Founded by Jeremy Howard and Rachel Thomas.

## Profile

fastai is both a library and an educational philosophy. The library layers on top of PyTorch to provide sensible defaults and best practices, making it possible to train powerful models with minimal code. The accompanying Practical Deep Learning for Coders course teaches both the library and the underlying principles.
