# Factory

**Type:** Organization / Enterprise AI Platform
**Also known as:** Factory.ai
**URL:** [https://factory.ai/](https://factory.ai/)
**Valuation:** $1.5B (Series C, Mar 2026)

## TL;DR

Factory is an agent-native software development platform built around "Droid." Unlike infrastructure vendors that sell tokens, Factory claims it is incentivized to reduce customer token spend. It offers Agent Readiness scoring, Mission Control for orchestrating parallel agent fleets, Droid Computers for persistent remote machines, and deep analytics by model and engineer.

## Key Products

- **Droid CLI** — Terminal-based agent interface
- **Desktop App** — Native macOS and Windows agent client
- **Web / Mobile** — Browser and mobile access
- **Slack Integration** — Agent collaboration inside Slack
- **Jira & Linear** — AI project manager for ticketing
- **Droid Computer** — Persistent cloud machines that keep state across sessions
- **Factory Analytics** — Token consumption breakdown and adoption tracking
- **Agent Readiness** — 100+ signal scoring for codebase maturity
