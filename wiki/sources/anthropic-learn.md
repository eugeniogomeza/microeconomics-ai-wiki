# Anthropic Learn — AI Learning Resources & Guides

**Author:** [[anthropic]]
**Published:** 2026 (ongoing)
**URL:** [https://www.anthropic.com/learn](https://www.anthropic.com/learn)

## TL;DR

Anthropic Learn (formerly Anthropic Academy) is the company's official learning hub featuring courses on AI Fluency, API development, Model Context Protocol, and Claude Code. Certificates are offered upon completion, and the content targets both individual developers and enterprise teams.

## Key Sections

- **Build with Claude** — Comprehensive API guides and best practices for developing Claude-powered applications.
- **Claude for Work** — Enterprise deployment guides, team-productivity playbooks, and organizational integration.
- **Claude for Personal** — Individual-focused guides for leveraging Claude in daily tasks and personal projects.
- **AI Fluency Newsletter** — Quarterly research, frameworks, and resources on human-AI collaboration.

## Featured Courses

- **Claude Code in Action** — Hands-on course for using Claude Code for software development.
- **Claude 101** — Foundational introduction to Claude models and capabilities.
- **Model Context Protocol (MCP)** — Protocol for connecting Claude to external tools and data sources.
