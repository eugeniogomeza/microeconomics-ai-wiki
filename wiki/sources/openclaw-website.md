# OpenClaw Website — Personal AI Assistant

**Author:** [[peter-steinberger]] (creator)
**Published:** 2026 (ongoing)
**URL:** [https://openclaw.ai/](https://openclaw.ai/)
**License:** Open Source

## TL;DR

OpenClaw is an open-source, locally-hosted personal AI assistant — often described as the "closest thing to early AGI." It runs on the user's own machine (Mac, Windows, Linux), connects to multiple chat apps (WhatsApp, Telegram, Discord, Slack, Signal, iMessage), and features persistent memory, browser control, system access, and a growing ecosystem of community skills.

## Key Claims

1. **Local-First & Private by Default** — Your data and context stay on your machine, not in a walled garden.
2. **Persistent Memory** — Remembers users across sessions and becomes uniquely theirs.
3. **Multi-Platform Chat** — Works in DMs and group chats across Telegram, Discord, Slack, WhatsApp, Signal, and iMessage.
4. **Full System Access** — Read/write files, run shell commands, execute scripts; sandboxed or full access.
5. **Browser Control** — Browse, fill forms, extract data from websites autonomously.
6. **Skills & Plugins** — Community skills + ability to self-write and hot-reload skills.
7. **Companion App (Beta)** — macOS menubar app for easy access; requires macOS 15+.

## Quick Start

- Install: `npm i -g openclaw` or `curl -fsSL https://openclaw.ai/install.sh | bash`
- Onboard: `openclaw onboard`
- Source install: `git clone https://github.com/openclaw/openclaw.git`
