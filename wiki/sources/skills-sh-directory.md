# Skills.sh — The Agent Skills Directory

**Author:** [[skills-sh]]
**Published:** 2026 (ongoing)
**URL:** [https://www.skills.sh/](https://www.skills.sh/)

## TL;DR

Skills.sh is the open agent skills ecosystem — a directory of reusable capabilities for AI agents installable with a single command (`npx skills add <owner/repo>`). It catalogs skills for 20+ agents including Claude Code, Cursor, Codex, Copilot, Windsurf, Gemini, Droid, OpenClaw, and others. The leaderboard tracks 419,430+ total installs.

## Key Claims

1. **Universal Skill Format** — One command installs capabilities across multiple agent platforms.
2. **Massive Catalog** — 419,430+ all-time installs with trending/hot leaderboards.
3. **Multi-Agent Support** — Supports Claude Code, Cursor, Codex, GitHub Copilot, Windsurf, Gemini, Cline, AMP, Antigravity, ClawdBot, Droid, Goose, Kilo, Kiro CLI, Nous Research, OpenCode, Roo, Trae, VS Code, and more.
4. **Community-Driven** — Skills contributed by open-source maintainers, companies, and individual developers.
