## TL;DR

Sentdex is Harrison Kinsley's YouTube channel and one of the longest-running Python/ML education resources on the platform. Unlike theory-first channels, Sentdex is relentlessly practical: open a terminal, write Python, run the code, see the result. The channel covers machine learning, deep learning with PyTorch and TensorFlow, reinforcement learning, computer vision, NLP, game AI, data analysis, and general Python programming. If you want to see someone train a model, deploy it, and diagnose bugs in real time, Sentdex is the canonical resource.

## Why It's Here

While Karpathy teaches deep learning from first principles and StatQuest teaches the math, Sentdex shows you how to make it work in practice. The channel bridges "I understand the concept" to "I can ship this." Its longevity (active since ~2012) gives it a breadth few channels match.

## Standout Content

### Practical Machine Learning with Python
- End-to-end tutorials using scikit-learn, pandas, numpy.
- Covers regression, classification, clustering, feature engineering, and model evaluation.
- Focus on real datasets and real problems, not toy examples.

### Neural Networks from Scratch
- Builds neural networks using only NumPy — no frameworks.
- Walks through forward/backward propagation, activation functions, loss functions, and optimization.
- One of the earliest widely viewed "neural net from scratch" video series on YouTube.

### Deep Learning with TensorFlow and PyTorch
- Complete courses on both frameworks.
- CNNs for image classification, RNNs/LSTMs for sequences, GANs for generation.
- Includes transfer learning, data augmentation, and deployment considerations.

### Reinforcement Learning Series
- Q-learning, DQN, policy gradient methods.
- Applied to OpenAI Gym environments (CartPole, MountainCar, Atari).
- Shows the gap between theory and working RL agents.

### Computer Vision and OpenCV
- Object detection, face detection, motion tracking.
- Integration of deep learning models (YOLO, SSD) with OpenCV.
- Practical robotics and automation projects.

### NLP and Large Language Models
- Practical text classification, sentiment analysis, named entity recognition.
- Fine-tuning transformers using HuggingFace.
- Recent coverage of LLM APIs and agents.

### Game AI and Simulation
- Building AI for games using RL and search algorithms.
- StarCraft II bot using PySC2.
- Demonstrates how AI concepts translate to interactive environments.

## Agent Notes

- Sentdex has been producing content since ~2012, making it one of the oldest continuously active ML education channels.
- The "from scratch" neural network series was a landmark resource for learners before PyTorch/TensorFlow became dominant.
- Harrison Kinsley's teaching style is unscripted and raw — he often debugs live, which is valuable for learning real-world problem solving.
- The breadth (Python, ML, finance, game dev, web dev) means not every video is AI-relevant; focus on the ML/DL playlists for this wiki.
